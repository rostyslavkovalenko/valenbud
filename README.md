# VALENBUD — Renovation Company Website

A responsive presentation website for a fictional renovation company.

## Project Goals

* Present the company's renovation and finishing services.
* Showcase example projects.
* Provide a convenient way for potential clients to request a quote.
* Create a modern, responsive user experience.

## Technologies

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* Vercel

## Features

* Responsive navigation
* Services section
* Project gallery
* Interactive FAQ
* Contact form with client-side validation

## Design

The visual identity uses an Ivory, Jade Green, Emerald Green, and Gold color palette.

In development.
