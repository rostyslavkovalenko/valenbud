# VALENBUD — Renovation Company Website

A responsive presentation website for a fictional renovation and finishing company based in Darłowo, Poland.

**Live website:** https://valenbud.vercel.app/
**GitHub repository:** https://github.com/rostyslavkovalenko/valenbud

## Project Goals

* Present the company's renovation and finishing services.
* Showcase illustrative interior project images.
* Provide a convenient way for potential clients to get in touch.
* Create a modern, responsive user experience.
* Practice professional web development workflows using Git, GitHub, and Vercel.

## Technologies

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* Vercel

## Features

* Responsive navigation with a mobile hamburger menu.
* Hero section with a background image.
* Company introduction section.
* Renovation and finishing services section.
* Project gallery with illustrative images.
* Interactive FAQ using HTML `<details>` elements.
* Contact section with company information.
* Responsive footer.
* Favicon and brand logo.
* Open Graph metadata for social link previews.

## Design

The visual identity uses the following color palette:

| Color         | HEX       |
| ------------- | --------- |
| Ivory         | `#FDFDD0` |
| Jade Green    | `#006850` |
| Emerald Green | `#004F2E` |
| Gold          | `#D4AF37` |

The design follows a Modern Premium direction, combining clean layouts, natural interior photography, and restrained accent colors.


## Running Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

No build process is required.

## Deployment

The website is hosted on Vercel and connected to the GitHub repository. Changes pushed to the `main` branch can trigger automatic deployments.
